# Glorycourse 수강 관리

[![Backend coverage](https://w00j00ng.github.io/glorycourse/coverage/backend.svg)](https://w00j00ng.github.io/glorycourse/coverage/) [![Frontend coverage](https://w00j00ng.github.io/glorycourse/coverage/frontend.svg)](https://w00j00ng.github.io/glorycourse/coverage/)

교회에서 학기별 강좌, 수강신청, 배정 결과와 수강이력을 관리하는 프로그램입니다. 자료는 **현재 PC에 저장**됩니다. 별도 서버나 개발 도구를 설치하지 않아도 됩니다.

## 다운로드

[배포 페이지](https://github.com/w00j00ng/glorycourse/releases)에 아래 실행 파일이 올라온 버전부터 사용할 수 있습니다. 파일이 보이지 않으면 아직 배포 전입니다.

| 사용하는 컴퓨터 | 다운로드 파일 | 실행 방법 |
| --- | --- | --- |
| Windows 11, Intel/AMD 64비트 | [Windows 다운로드](https://github.com/w00j00ng/glorycourse/releases/latest/download/glorycourse-windows-x64.zip) | `시작.cmd` 두 번 클릭 |
| macOS 15 이상, Apple M 시리즈 | [Mac 다운로드](https://github.com/w00j00ng/glorycourse/releases/latest/download/glorycourse-macos-arm64.zip) | `Glorycourse.app`을 열고 **시작** 선택 |
| Ubuntu 24.04 LTS, GNOME, Intel/AMD 64비트 | [Linux 다운로드](https://github.com/w00j00ng/glorycourse/releases/latest/download/glorycourse-linux-x64.tar.gz) | `시작.sh`를 **프로그램으로 실행** |

Mac/Linux는 현재 시험 배포 대상입니다. 해당 OS의 첫 실행 검증과 Mac 서명·공증을 완료하기 전에는 정식 지원으로 안내하지 않습니다. Intel Mac과 Windows ARM은 이번 배포 대상에 포함되지 않습니다.

**초록색 Code 버튼의 Download ZIP이나 Source code 파일은 실행 프로그램이 아닙니다.** 위 파일을 선택하세요. Node.js, npm, Git 설치는 필요하지 않습니다.

## 처음 시작하기

1. 다운로드한 압축 파일을 **모두 압축 해제**합니다. 압축 파일 안에서 바로 실행하지 마세요.
2. 풀린 `Glorycourse` 폴더를 열고 위 표의 시작 파일을 실행합니다. Mac은 앱 안의 파일을 따로 옮기지 마세요.
3. 잠시 기다리면 기본 웹 브라우저에 수강 관리 화면이 열립니다. 시작 파일을 다시 실행하면 사용 중인 화면을 다시 엽니다.

Windows에서는 작은 실행 창이 잠깐 나타날 수 있습니다. 오류가 나면 창을 닫기 전에 안내 문구를 확인하세요. **Windows의 PC 보호 또는 조직 정책으로 차단되면 배포 페이지의 출처와 해당 버전 안내를 확인하고 관리자에게 문의하세요.**

Mac에서 개발자 확인 경고가 나오면 출처를 확인한 뒤 [Apple의 앱 열기 안내](https://support.apple.com/ko-kr/102445)를 따르세요. 조직 정책으로 차단된 경우 관리자에게 문의하세요. 보안 기능 전체를 끌 필요는 없습니다.

Linux에서 텍스트 편집기로 열리면 파일을 닫고 `시작.sh`를 오른쪽 클릭해 **속성 → 권한 → 프로그램으로 실행 허용**을 확인한 다음 **프로그램으로 실행**을 선택하세요. 종료·자료 폴더 파일도 같은 방법입니다.

## 프로그램 사용 방법

처음 열면 **홈**에서 현재 학기와 **다음 할 일**을 안내합니다. 왼쪽 위 **Glorycourse** 로고나 **홈** 메뉴를 누르면 돌아올 수 있습니다. 각 업무 화면의 **?** 버튼에서도 사용 방법을 확인할 수 있습니다.

다음 순서로 한 학기의 업무를 진행하세요.

| 순서 | 메뉴 | 할 일 |
| --- | --- | --- |
| 1 | **학기·강좌 관리** | **학기 관리**에서 학기를 추가하고, **개설 강좌 관리**에서 강좌와 정원을 입력한 뒤 **강좌 정보 저장**을 누릅니다. |
| 2 | **수강신청** | **신청 양식**에서 학기를 선택해 Excel을 받습니다. 작성한 파일을 **Excel 업로드**로 검토하고 **업무 자료에 반영**하거나, **신청 등록**으로 직접 입력합니다. |
| 3 | **배정초안** | **초안 생성** 후 자동 결과를 확인하고 필요한 최종 결정을 수정합니다. 행의 저장을 누르면 바로 반영되므로 **닫기**로 나중에 계속 검토할 수 있습니다. **확정 → 검토 내용으로 확정**을 누르면 수강이력에 반영되고 초안은 목록에서 제거됩니다. |
| 4 | **수강이력** | 확정된 명단을 확인하고 안내 상자의 **현재 학기 현황 다운로드**를 누릅니다. 홈에서 **현재 학기 업무가 완료되었습니다**를 확인합니다. |

- **현재 학기**는 학기 순서가 가장 큰 학기입니다. 새 학기의 순서를 비워두면 다음 번호가 자동 지정되고, 목록에는 최신 학기가 먼저 나옵니다.
- 기존에 관리하던 수강이력은 **이력 양식 → Excel 업로드** 또는 **이력 등록**으로 바로 입력할 수 있습니다. 과거 수강신청이나 배정초안을 만들 필요가 없습니다.
- 회원명으로 검색하고 학기·강좌를 선택해 목록을 좁힐 수 있습니다. 수강신청·배정초안·수강이력 목록 아래의 **이전 / 다음**으로 페이지를 이동합니다.
- 일반 **현황 다운로드**는 검색 조건에 맞는 전체 결과를 받는 기능입니다. **업무 완료 표시는 `현재 학기 현황 다운로드` 버튼을 기준으로 합니다.** 자료가 변경되면 다시 내려받아야 할 수 있습니다.
- **자료 관리 → 현재 자료 백업**은 필요할 때 사용합니다. 백업 여부는 학기 업무 완료 조건에 포함하지 않습니다.

강좌 일괄 입력, Excel 작성 예시, 삭제 시 영향과 완료 조건은 [상세 사용 설명서](docs/usage.md)를 참고하세요. 이 안내는 현재 소스 기준이며, 설치한 배포본에 버튼이 없다면 해당 Release의 변경 내역과 버전을 확인하세요.

## 프로그램 종료하기

- 화면 오른쪽 위 **프로그램 종료**를 누릅니다. 저장하지 않은 입력을 확인하고, **종료됨** 안내가 나오면 브라우저 탭을 닫으세요.
- 화면을 이미 닫았다면 Windows는 `종료.cmd`, Linux는 `종료.sh`를 실행합니다. Mac은 `Glorycourse.app`을 다시 열고 **종료**를 선택합니다.
- **브라우저 탭만 닫으면 프로그램은 계속 실행됩니다.** 모든 탭이 같은 프로그램을 사용하므로 종료하면 다른 탭도 사용할 수 없습니다.

저장이 진행 중이면 완료 후 종료합니다. 종료 파일은 화면에 입력만 해둔 내용을 저장해 주지 않으므로, 필요한 내용을 먼저 저장하세요.

## 자료와 백업

화면의 **자료 폴더 열기** 버튼으로 자료 위치를 확인할 수 있습니다. Windows/Linux는 `자료 폴더` 파일, Mac은 앱의 **자료 폴더** 메뉴로도 열 수 있습니다.

| 컴퓨터 | 기본 자료 폴더 |
| --- | --- |
| Windows | 사용자 폴더의 `AppData\Local\Glorycourse` |
| Mac | 사용자 폴더의 `Library/Application Support/Glorycourse` |
| Linux | 사용자 폴더의 `.local/share/glorycourse` (별도 XDG 설정이 있으면 그 위치) |

화면의 **자료 관리 → 현재 자료 백업**으로 백업을 만드세요. 백업 파일은 자료 폴더 안 `backups`에 있습니다. 최근의 정상 백업과 자료 버전이 같으면 새 파일을 만들지 않습니다. 신청·이력 수정, Excel 반영, 배정 확정 때는 백업을 자동 생성하지 않습니다. PC 고장에 대비해 필요한 시점에 직접 백업하고 USB나 다른 저장 장치에도 복사해 두세요.

복원할 때는 **자료 관리 → 백업 파일 복원**에서 `.sqlite` 백업 파일을 선택하고, 검토 내용과 경고를 확인한 뒤 확인 메모를 입력해 복원합니다. 현재 자료는 복원 직전에 자동 백업됩니다. 실행 중에 `db.sqlite` 파일을 직접 바꾸지 마세요.

**Excel 현황 파일과 자료 백업은 용도가 다릅니다.** 현황 파일은 명단 확인·공유용이며, 프로그램 전체 자료를 복원하려면 `.sqlite` 백업이 필요합니다.

## 새 버전으로 바꾸기

1. 현재 화면에서 백업을 만들고 프로그램을 종료합니다.
2. 새 버전을 내려받아 **새 폴더에 모두 압축 해제**합니다.
3. 새 폴더의 시작 파일을 실행하고 기존 자료를 확인합니다. 같은 사용자 계정이면 기존 자료 폴더를 계속 사용합니다. 필요한 자료 형식 변경은 시작할 때 자동으로 적용되며, 변경 전 파일은 자료 폴더의 `update-backups`에 보관됩니다.

자료 형식 변경에 실패하면 프로그램이 시작되지 않고 기존 자료를 그대로 둡니다. 안내된 오류와 자료 폴더의 `launcher.log`를 확인하세요. 이전 버전이 실행 중이면 먼저 종료한 뒤 새 버전을 시작하세요.

프로그램을 지울 때는 먼저 종료하고 압축을 푼 프로그램 폴더를 삭제하면 됩니다. **자료 폴더는 남습니다.** 자료까지 삭제하려면 필요한 백업을 다른 위치에 보관한 뒤 자료 폴더를 별도로 삭제하세요.

## 문제가 생겼을 때

시작 파일을 다시 실행해 보세요. 종료 중이라는 안내가 나오면 잠시 기다렸다가 실행하세요. 해결되지 않으면 [문의 등록](https://github.com/w00j00ng/glorycourse/issues)에 운영체제, 배포 버전, 화면의 오류 문구를 적어 주세요.

배포 폴더의 `release.json`에 버전이 있고(Mac은 앱 패키지 안 `Contents/Resources/app`), 자료 폴더의 `launcher.log`에 실행 기록이 있습니다. 문의에는 학생 명단, 백업 파일, 개인정보를 첨부하지 마세요.

## 테스트 커버리지

모노레포의 백엔드와 프런트엔드를 따로 집계합니다. 배지는 줄 커버리지를 표시하며, 미실행 파일도 0%로 포함합니다.

기본 브랜치의 성공한 [Coverage CI](https://github.com/w00j00ng/glorycourse/actions/workflows/coverage.yml)가 [현재 커버리지 보고서](https://w00j00ng.github.io/glorycourse/coverage/)와 배지를 갱신합니다. 파일별 결과는 해당 실행의 `coverage-report`에서 확인할 수 있습니다.
