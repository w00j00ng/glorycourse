# Excel 등록 검토 규칙

수강신청 양식은 버전 `2`이며 기본 다운로드는 `학기명 | 회원명 | 신청순서 | 1순위 강좌 | 2순위 강좌 | 3순위 강좌`로 제공한다. 사용자가 오른쪽에 `4순위 강좌`·`5순위 강좌` 열을 추가하면 함께 읽는다. 순위 열은 반복 처리하며 `MAX_CHOICES_PER_APPLICATION = 5` 상수로 허용 개수와 순위를 제한한다. 학기·회원당 한 행만 허용하고 같은 행에 같은 강좌를 두 번 입력할 수 없다. 빈 열은 선택지로 만들지 않으며 뒤 열의 순위는 유지한다. 2~5순위는 비워도 된다. 모든 희망 강좌가 공란이면 오류다. 이전 여러 행 양식과 6순위 열은 지원하지 않는다. 원본 보관·내보내기는 사용자가 추가한 순위 열과 값도 보존한다.

수강이력 Excel은 기존 기록을 옮기는 용도이므로, 새 학기와 강좌가 없으면 등록 과정에서 생성한다. 새 학기에는 다음 학기 순서를 부여한다. 직접 등록·일괄 등록·Excel 등록으로 새로 생성하는 개설강좌의 정원은 해당 등록 작업에서 그 학기·강좌에 저장하는 학생 수로 설정한다. 이후 이력을 추가·수정·삭제해도 기존 정원은 바꾸지 않는다. Excel 검토 화면에서 새 학기 순서와 정원 설정은 `안내`로 보여 주며 확인 메모 없이 반영할 수 있다. 안내 옆 `닫기` 버튼은 해당 문구만 숨기고 저장 대상이나 검증 결과를 바꾸지 않는다.

이미 등록된 학기·개설강좌의 순서 또는 정원이 미정인 경우에는 기존 경고를 유지한다. 정원 초과, 재수강, 중복 이력 등 다른 경고·오류도 유지한다. 같은 Excel 안에서 첫 이력 행이 새 학기·개설강좌를 생성한 뒤 이어지는 행도 업로드 전 기준으로 동일하게 안내 처리한다.

`입력 경고 무시`는 기본으로 체크하지 않는다. 신청·이력 입력, Excel 검토의 체크박스는 같은 설정을 제어한다. 체크하면 신청·이력 등록의 안내·경고 목록과 경고 확인 창을 생략하고 사용자에게 확인 메모를 요구하지 않는다. 서버에 전달하는 확인 사유에는 설정으로 확인을 생략했다는 사실을 기록한다. 체크를 해제하면 경고를 표시하고 확인 메모를 받는다. 이 설정은 현재 실행 화면에만 적용되며 화면을 새로 열면 체크가 해제된다. 오류 표시·저장 차단, 충돌 해결 입력, 배정 확정·백업 복원 확인에는 영향을 주지 않는다.

파일 선택이나 신청 반영 방식이 바뀌면 이전 검토 결과를 무효화하고 파일 검토 버튼을 다시 표시한다. 이전 요청이 늦게 완료되어도 새 파일의 검토 결과를 덮어쓰지 않는다. 검토 항목 문구는 한 줄로 표시하고 넘치는 부분은 말줄임하며 툴팁에 전체 문구를 제공한다.

수강신청 Excel의 `개설강좌` 시트에서 학기명·강좌명이 있는 행의 정원이 공란이면 기존 시스템 정원 유무와 관계없이 행 위치가 표시되는 오류로 처리한다. 같은 강좌의 여러 행 중 하나라도 공란이면 오류다. 정원 `0`은 유효하다. 개설강좌 행 없이 신청 강좌만 적은 경우에는 시스템에 해당 학기·강좌의 정원이 설정되어 있을 때만 반영한다. 오류가 있으면 화면과 서버 모두 전체 반영을 막으며 기존 자료를 변경하지 않는다.

검증은 실제 등록과 Excel 검토·반영을 호출하여 새 학기·강좌 생성, 최초 학생 수에 따른 정원, 이후 정원 유지, 안내 닫기, 경고 끄기·다시 켜기, 메모 생략, 오류 유지, 정원 공란·`0`·기존 정원·강좌 행 누락, 원자적 거부를 확인한다. 문구는 개발자용 코드 대신 한국어로 표시한다.
