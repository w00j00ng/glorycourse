# Excel 등록 검토 규칙

수강이력 Excel은 기존 기록을 옮기는 용도이므로, 새 학기와 강좌가 없으면 등록 과정에서 생성한다. 새 학기에는 다음 학기 순서를 부여하고 새 개설강좌의 정원은 미정으로 둔다. 이 두 결과는 검토 화면에서 `안내`로 보여 주며 확인 메모 없이 반영할 수 있다. 안내 옆 `닫기` 버튼은 해당 문구만 숨기고 저장 대상이나 검증 결과를 바꾸지 않는다.

이미 등록된 학기·개설강좌의 순서 또는 정원이 미정인 경우에는 기존 경고를 유지한다. 정원 초과, 재수강, 중복 이력 등 다른 경고·오류도 유지한다. 같은 Excel 안에서 첫 이력 행이 새 학기·개설강좌를 생성한 뒤 이어지는 행도 업로드 전 기준으로 동일하게 안내 처리한다. 직접 등록·수정의 경고 정책은 바꾸지 않는다.

수강신청 Excel의 `개설강좌` 시트에서 학기명·강좌명이 있는 행의 정원이 공란이면 기존 시스템 정원 유무와 관계없이 행 위치가 표시되는 오류로 처리한다. 같은 강좌의 여러 행 중 하나라도 공란이면 오류다. 정원 `0`은 유효하다. 개설강좌 행 없이 신청 강좌만 적은 경우에는 시스템에 해당 학기·강좌의 정원이 설정되어 있을 때만 반영한다. 오류가 있으면 화면과 서버 모두 전체 반영을 막으며 기존 자료를 변경하지 않는다.

검증은 실제 Excel의 검토 결과와 반영을 호출하여 새 학기·강좌 생성, 안내 닫기, 메모 생략, 기존 경고 유지, 정원 공란·`0`·기존 정원·강좌 행 누락, 원자적 거부를 확인한다. 문구는 개발자용 코드 대신 한국어로 표시한다.
