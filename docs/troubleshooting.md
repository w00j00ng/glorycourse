# Glorycourse 문제 해결

[사용 설명서](usage.md) · [배포 페이지](https://github.com/w00j00ng/glorycourse/releases)

먼저 화면의 오류 문구를 그대로 확인하세요. 저장·복원처럼 자료를 바꾸는 작업 중이었다면 시작 파일이나 반영 버튼을 반복해서 누르기 전에 아래 항목을 확인합니다.

## 실행과 종료

| 보이는 현상 | 확인할 것과 해결 방법 |
| --- | --- |
| 압축 파일에서 실행했는데 창이 바로 닫힘 | 내려받은 파일을 **모두 압축 해제**한 뒤, 풀린 `Glorycourse` 폴더의 시작 파일을 실행합니다. GitHub의 **Code → Download ZIP**은 실행 프로그램이 아닙니다. |
| 시작 창만 잠깐 보이고 브라우저가 열리지 않음 | 잠시 기다린 뒤 시작 파일을 한 번 더 실행합니다. 그래도 열리지 않으면 Windows의 `자료 폴더.cmd`, Linux의 `자료 폴더.sh`, Mac 앱의 **자료 폴더**를 이용해 자료 폴더를 열고 `launcher.log`의 마지막 오류 문구를 확인합니다. 프로그램 폴더의 일부 파일이 없다면 [배포 페이지](https://github.com/w00j00ng/glorycourse/releases)에서 다시 받아 **새 폴더**에 압축을 풉니다. |
| 이미 실행 중이거나 자료 폴더를 사용 중이라는 안내 | 실행 중인 창이나 브라우저를 확인합니다. 같은 버전이 이미 실행 중이면 시작 파일을 다시 열어 기존 화면에 접속할 수 있습니다. 다른 버전을 쓰고 있거나 종료 중이면 기존 프로그램을 종료하고 잠시 기다린 뒤 시작합니다. 실행 중인 자료 폴더의 잠금 파일을 직접 지우지 마세요. |
| 브라우저를 닫았는데 프로그램이 계속 실행됨 | 브라우저 탭은 화면일 뿐입니다. **프로그램 종료**를 누르거나 Windows는 `종료.cmd`, Linux는 `종료.sh`, Mac은 앱의 **종료**를 사용합니다. |
| 새 버전에서 자료를 찾을 수 없음 | 이전 버전과 **같은 컴퓨터 사용자 계정**으로 실행했는지 확인합니다. 자료는 프로그램 압축을 푼 폴더가 아니라 별도의 사용자 자료 폴더에 저장됩니다. **자료 폴더 열기**로 위치를 확인하고 다른 PC로 옮겼다면 `.sqlite` 백업을 복원합니다. |

Windows의 PC 보호나 조직 정책이 실행을 막으면 배포 출처와 버전을 확인하고 컴퓨터 관리자에게 문의하세요. Mac의 개발자 확인 경고는 [Apple의 앱 열기 안내](https://support.apple.com/ko-kr/102445)를 따르세요. Linux에서 시작 파일이 텍스트로 열리면 파일을 오른쪽 클릭해 **속성 → 권한 → 프로그램으로 실행 허용**을 확인하고 **프로그램으로 실행**을 선택하세요. 보안 기능 전체를 끌 필요는 없습니다.

## 화면과 업무 자료

| 보이는 현상 | 확인할 것과 해결 방법 |
| --- | --- |
| 홈에 생각한 학기가 현재 학기로 나오지 않음 | **학기·강좌 관리 → 학기 관리**에서 순서를 확인합니다. 이름이나 날짜가 아니라 **학기 순서가 가장 큰 학기**가 현재 학기입니다. 행의 위로·아래로 버튼으로 순서를 바꿀 수 있습니다. |
| 강좌를 추가했는데 보이지 않음 | **목록에 추가** 또는 **선택 강좌 추가** 뒤 **강좌 정보 저장**을 눌렀는지 확인합니다. 선택 학기도 확인하세요. |
| 초안 생성 전에 정원 입력을 요구함 | 현재 학기의 개설 강좌마다 정원을 확인합니다. **빈칸은 미정**, `0`은 정원이 0명이라는 뜻입니다. |
| Excel 업로드에서 개설강좌 정원 오류 | `개설강좌` 시트에서 입력한 모든 강좌의 정원을 채웁니다. 프로그램에 기존 정원이 있어도 **파일의 정원 빈칸은 오류**입니다. 정원이 없다면 `0`을 입력할 수 있지만 배정 가능 인원도 0명입니다. |
| Excel을 검토했는데 목록에 자료가 없음 | 검토는 저장이 아닙니다. 경고·충돌을 확인한 뒤 **업무 자료에 반영**을 눌러야 합니다. 반영 후 학기·회원명 검색 조건도 확인하세요. |
| 기존값 유지와 파일값 적용 중 무엇을 고를지 모름 | 학기 순서·정원이 시스템 값과 파일 값에서 다를 때 고릅니다. **기존값 유지**는 현재 자료를 바꾸지 않고, **파일값 적용**은 업로드한 값으로 바꿉니다. 어느 값이 실제 운영 기준인지 확인한 뒤 선택하세요. [정원 10명과 12명 예시](usage.md#excel로-등록하기)를 참고할 수 있습니다. |
| 배정초안이 오래되었다는 안내 | 초안을 만든 뒤 신청·수강이력·강좌 설정이 달라졌습니다. 변경 내용을 확인하고 **새 초안**을 생성해 다시 검토하세요. |
| 배정 확정에서 경고나 오류가 표시됨 | 어떤 회원·강좌에 대한 안내인지 확인합니다. **오류**는 내용을 고쳐 다시 검토해야 합니다. **경고**는 결과를 확인하고 필요한 경우 확인 사유를 기록합니다. 정원 초과처럼 의도하지 않은 배정은 최종 결정을 수정하세요. |
| 백업했는데 홈에 업무 완료가 표시되지 않음 | 백업은 완료 조건이 아닙니다. 현재 학기의 신청·배정을 확정하고 **수강이력 → 현재 학기 현황 다운로드**로 명단을 확인합니다. 일반 **현황 다운로드**는 완료 표시를 바꾸지 않습니다. |
| 현재 학기 현황을 받았는데 다시 확인하라고 나옴 | 다운로드 후 자료가 바뀌었을 수 있습니다. 수강이력을 다시 확인하고 **현재 학기 현황 다운로드**를 다시 사용하세요. |

수강이력은 수강신청·배정초안 없이도 직접 등록할 수 있습니다. 과거 자료를 옮길 때 새 학기와 강좌가 생겼다는 안내는 이력을 등록할 수 있다는 뜻이며, 새 강좌의 정원은 미정으로 남습니다. 다음 학기의 신청을 받기 전에 정원을 입력하세요.

## 백업, 복원, 업데이트

- **현황 Excel은 전체 자료 백업이 아닙니다.** 복원할 자료를 보관하려면 **자료 관리 → 현재 자료 백업**으로 만든 `.sqlite` 파일을 다른 저장 장치에도 복사하세요.
- **백업 파일 복원**은 현재 자료를 선택한 백업 시점으로 되돌립니다. 파일과 검토 결과를 확인하고 확인 메모를 입력하세요. 복원 직전 자료는 안전 사본으로 보관됩니다.
- 업데이트할 때는 현재 자료를 백업하고 프로그램을 종료한 뒤, 새 버전을 **새 폴더에** 압축 해제해 시작합니다. 같은 사용자 계정이라면 기존 자료 폴더를 계속 사용합니다. 자료 형식 변경에 실패하면 기존 자료를 그대로 두고 시작을 멈춥니다.
- 자료 폴더는 화면 오른쪽 위 **자료 폴더 열기**로 확인합니다. Windows는 `AppData\Local\Glorycourse`, Mac은 `Library/Application Support/Glorycourse`, Linux는 `.local/share/glorycourse`가 기본 위치입니다. 프로그램 폴더를 삭제해도 이 자료 폴더는 남습니다.

## 해결되지 않을 때

[GitHub 문의 등록](https://github.com/w00j00ng/glorycourse/issues)에 사용하는 운영체제, 배포 버전, 어떤 버튼을 눌렀는지, 화면의 오류 문구를 적어 주세요. 버전은 배포 폴더의 `release.json`에서 확인할 수 있습니다. Mac은 앱 패키지 안 `Contents/Resources/app/release.json`에 있습니다. 실행 기록이 필요하면 자료 폴더의 `launcher.log`에서 관련 오류 문구만 확인하세요.

**실제 회원 명단, 업로드한 Excel, `.sqlite` 백업 파일, 실행 기록 전체를 공개 문의에 첨부하지 마세요.**
