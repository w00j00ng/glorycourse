# Glorycourse 사용 설명서

[처음 사용하기](#처음-사용하기) · [한 학기 따라 하기](#한-학기-따라-하기) · [기존 수강이력 옮기기](#기존-수강이력-옮기기) · [문제 해결](troubleshooting.md)

Glorycourse는 한 PC에서 교회 관리자가 학기별 수강 업무를 처리하는 프로그램입니다. 다른 PC로 자료가 자동 공유되지는 않습니다. 이 문서는 화면을 처음 쓰는 담당자를 위한 설명입니다. 설치한 버전의 기능은 [배포 페이지](https://github.com/w00j00ng/glorycourse/releases)의 변경 내역과 함께 확인하세요.

## 처음 사용하기

1. [배포 페이지](https://github.com/w00j00ng/glorycourse/releases)에서 컴퓨터에 맞는 실행 파일을 내려받습니다. GitHub의 **Code → Download ZIP**은 실행 프로그램이 아닙니다.
2. 압축을 모두 풀고 `Glorycourse` 폴더에서 Windows는 `시작.cmd`, Linux는 `시작.sh`, Mac은 `Glorycourse.app`을 엽니다. 개발 도구를 설치하거나 계정을 만들 필요는 없습니다.
3. 브라우저에 열린 **홈**의 **다음 할 일**을 누릅니다. 처음 자료가 없다면 **학기 추가**부터 안내합니다.
4. 사용을 마치면 화면 오른쪽 위 **프로그램 종료**를 누릅니다. 브라우저 탭만 닫으면 프로그램은 계속 실행됩니다. 브라우저를 먼저 닫았다면 Windows는 `종료.cmd`, Linux는 `종료.sh`, Mac은 앱의 **종료**를 사용합니다.

Windows 11의 Intel/AMD 64비트 PC가 현재 주요 배포 대상입니다. macOS 15 Apple Silicon과 Ubuntu 24.04 Intel/AMD 64비트는 시험 배포 대상이므로 각 버전의 배포 안내도 확인하세요.

화면은 브라우저에 보이지만 자료는 이 컴퓨터의 자료 폴더에 저장됩니다. 신청·수강이력은 **현황 다운로드**로 받은 Excel을 보관하고 다시 업로드할 수 있습니다. 두 파일에는 학생 소속이, 수강이력 파일에는 정원과 메모도 포함됩니다. 시작·종료에 문제가 있으면 [문제 해결](troubleshooting.md)을 보세요.

## 화면에 나오는 말

| 말 | 뜻 |
| --- | --- |
| **학기** | 강좌를 열고 신청을 받는 기간입니다. **학기 순서**가 가장 큰 학기가 현재 학기이며 목록 맨 앞에 표시됩니다. 순서가 없는 과거 학기는 뒤에 표시됩니다. |
| **개설 강좌** | 특정 학기에 열리는 강좌와 정원입니다. 정원 0명은 빈칸과 다릅니다. |
| **수강신청** | 회원이 원하는 강좌와 희망순위입니다. 아직 수강이 확정된 기록은 아닙니다. |
| **배정초안** | 자동 배정은 신청을 바탕으로 결과를 제안하고, 수동 초안은 신청 없이 회원을 직접 추가할 수도 있습니다. 관리자가 최종 결정을 저장하고 확정할 수 있습니다. |
| **수강이력** | 실제로 확정하거나 직접 등록한 수강 기록입니다. 신청이나 초안을 수정·삭제해도 이력은 그대로 남습니다. |
| **학생 소속** | 신청·초안·이력마다 보관하는 해당 시점의 부서·교구·학교 등입니다. 선택 입력이며 같은 회원도 기록별로 다를 수 있습니다. |
| **현황 다운로드** | 검색 조건에 맞는 신청·수강이력 Excel을 받습니다. 학생 소속, 신청의 학기 순서·개설강좌와 이력의 정원·메모도 보관하며 배정초안·시스템 기록은 포함하지 않습니다. |

## 한 학기 따라 하기

예를 들어 `2026년 가을학기`에 `창세기` 10명, `마태복음` 20명, `마가복음` 15명을 열고 두 회원의 신청을 받는 경우입니다. 아래 이름은 설명용 가상 이름입니다.

1. **학기·강좌 관리 → 학기 관리 → 학기 추가**에서 `2026년 가을학기`를 만듭니다. **개설 강좌 관리**로 이동해 세 강좌와 정원을 입력하고 **강좌 정보 저장**을 누릅니다. 목록에 강좌와 정원이 보이면 준비가 끝났습니다.
2. **수강신청 → 신청 양식**에서 이 학기를 선택해 파일을 내려받습니다. `수강신청` 시트에 김믿음의 1순위 `창세기`, 2순위 `마태복음`과 이은혜의 1순위 `마가복음`을 적습니다. **Excel 업로드 → 파일 검토 → 업무 자료에 반영** 순서로 진행합니다. 수강신청 목록에서 두 회원의 희망 강좌가 보이면 등록된 것입니다. 소량이면 **신청 등록**으로 직접 입력해도 됩니다.
3. **배정초안 → 초안 생성**에서 학기와 배정 정책을 고릅니다. 자동 결과를 살펴보고 필요한 행의 **최종 결정**을 바꾼 뒤 해당 행의 **저장**을 누릅니다. **닫기**로 나중에 이어 볼 수 있습니다. 검토를 마치면 **확정 → 검토 내용으로 확정**을 누릅니다. 진행 중 초안 목록에서 사라지고 수강이력에 결과가 보이면 확정된 것입니다.
4. **수강이력**에서 학기를 선택해 명단을 확인합니다. 안내 상자의 **현재 학기 현황 다운로드**를 누르고 내려받은 Excel도 확인합니다. **홈**에 **현재 학기 업무가 완료되었습니다**가 나타나면 한 학기의 신청·배정 업무를 마친 것입니다. 일반 **현황 다운로드**만으로는 완료 표시가 바뀌지 않습니다.
5. 자료를 따로 보관할 시점에는 검색·필터를 해제하고 신청·수강이력의 **현황 다운로드**로 받은 Excel을 USB 등 다른 저장 장치에도 복사합니다.

중간에 무엇을 할지 헷갈리면 **홈**의 **다음 할 일**을 확인하세요. 아래 메뉴별 설명에서 각 단계를 더 자세히 볼 수 있습니다.

## 기존 수강이력 옮기기

이 프로그램을 쓰기 전부터 관리하던 명단은 **수강이력 → 이력 양식 → Excel 업로드**로 옮깁니다. `수강이력` 시트에 학기명, 회원명, 강좌명과 선택 사항인 학생 소속·관리자 메모를 적고 파일을 검토한 뒤 반영하세요. 새 학기와 강좌도 함께 등록할 수 있으므로 과거 신청서나 배정초안을 다시 만들 필요가 없습니다. `개설강좌` 시트에 정원을 입력하면 그 값을 사용합니다. 해당 강좌 행을 생략한 경우에만 새 강좌 정원을 첫 등록 작업의 학생 수로 설정하며, 이후 이력을 추가해도 자동으로 바뀌지 않습니다. 필요하면 **학기·강좌 관리**에서 정원을 수정하세요. 몇 건이라면 **이력 등록**으로 직접 입력할 수 있습니다.

이력 목록에서 학기와 회원명을 검색해 건수가 맞는지 확인하고 필요하면 **현황 다운로드**로 Excel을 받아 원본 명단과 비교하세요. 수강이력은 신청과 독립된 기록이므로, 과거 이력만 옮긴 학기가 홈에서 **업무 완료**로 표시되지 않아도 이력 저장에는 문제가 없습니다.

## 홈과 공통 사용법

- **홈** 또는 왼쪽 위 **Glorycourse** 로고로 대시보드에 이동합니다. 새 주소로 시작하거나 알 수 없는 화면 주소를 열면 홈이 표시됩니다.
- 대시보드에서 현재 학기명, 개설 강좌 수, 신청 인원, 배정초안 상태, 확정 수강이력 인원과 가장 먼저 할 일을 확인합니다. 안내 버튼을 누르면 해당 업무 화면으로 이동합니다.
- 현재 학기는 **학기 순서가 가장 큰 학기**입니다. 학기명이나 오늘 날짜로 판단하지 않습니다. 순서가 없는 과거 학기는 목록 뒤에 표시되고 현재 학기로 선택되지 않습니다.
- 각 업무 화면 오른쪽 위 **?**를 누르면 간단한 도움말이 열립니다.
- 업무 버튼에 마우스를 올리면 짧은 안내가 표시됩니다. 왼쪽 메뉴의 **버튼 도움말 표시**를 해제하면 숨길 수 있습니다. 페이지를 이동해도 설정은 유지되며, 화면을 새로 열면 기본으로 표시됩니다.
- 새로고침하면 현재 페이지는 유지됩니다. 저장 전 입력, 검색 조건, 열린 창까지 보존되는 것은 아니므로 먼저 저장하세요.
- 신청·이력은 회원명 일부로 검색하고, 학기·강좌는 드롭다운에서 선택합니다. 수강신청은 처음에 **현재 학기**가 선택되며 **전체**를 선택하면 모든 학기 신청을 볼 수 있습니다. 수강신청은 페이지당 10·20·50건 중 선택할 수 있고 처음에는 50건이 표시됩니다. 아래 **이전 / 다음**으로 이동합니다.

## 1. 학기와 강좌 준비

1. **학기·강좌 관리 → 학기 관리 → 학기 추가**를 누르고 학기명(예: `2026년 가을학기`)을 입력합니다.
2. 새 학기는 목록 맨 위의 가장 최근 학기로 추가됩니다. 중간에 넣으려면 해당 행의 **아래로**를 눌러 원하는 위치로 옮깁니다. 위로·아래로 버튼 대신 학기 행에 초점을 둔 뒤 키보드 ↑/↓를 눌러도 됩니다.
3. 학기명을 바꾸려면 목록에서 **수정**을 눌러 **학기 정보 저장**을 누릅니다. 선택된 행의 **선택됨**을 다시 누르면 선택이 해제됩니다.
4. **개설 강좌 관리**에서 학기를 선택하고 강좌와 정원을 준비한 뒤 **강좌 정보 저장**을 누릅니다. 강좌를 목록에 추가하는 것만으로는 저장되지 않습니다.

**정렬**에서 강좌명 가나다순·역순 또는 정원 낮은 순·높은 순을 선택합니다. 기본은 **등록순**이며 정원 미정은 정원 정렬에서 마지막에 표시합니다. 정렬을 바꿔도 저장 전 입력값은 유지됩니다. 강좌 추가·가져오기·저장·목록 새로고침 후에도 선택한 정렬을 적용합니다.

신청·수강이력·배정초안·확정 기록이 없는 학기만 **학기 삭제**를 할 수 있습니다. 학기를 삭제하면 그 학기의 개설 강좌도 함께 제거됩니다. 다른 학기에서도 쓰는 강좌명은 유지됩니다.

### 여러 강좌를 한 번에 추가하기

**여러 강좌 추가**에서 한 줄에 `강좌명, 정원`을 입력합니다.

```text
창세기, 10
마태복음, 20
마가복음, 15
```

Excel에서 강좌명·정원 두 열을 복사해 그대로 붙여넣을 수도 있습니다. 새 강좌의 정원은 필수이며 0 이상의 정수로 입력합니다. 쉼표는 강좌명과 정원을 구분하므로 강좌마다 줄을 바꾸세요.

**목록에 추가 → 강좌 정보 저장** 순서로 누릅니다. 같은 이름의 강좌는 중복 추가하지 않습니다.

### 이전 학기 강좌 가져오기

**이전 학기에서 가져오기**를 눌러 원본 학기를 선택하고 가져올 강좌를 체크합니다. **선택 강좌 추가**를 누르면 강좌명과 정원이 복사됩니다. 원본 정원이 비어 있다면 입력하고 **강좌 정보 저장**을 누르세요. 수강신청과 수강이력은 복사하지 않습니다.

### 이름 변경과 삭제

- 학기명을 바꾸면 해당 학기의 신청·이력에 변경된 이름이 표시됩니다.
- 강좌명 변경은 같은 강좌를 쓰는 **다른 학기와 수강이력에도 반영**됩니다. 과거 이름을 유지하려면 별도 강좌로 추가하세요.
- 선택 학기의 강좌에 수강이력이 있으면 삭제할 수 없습니다.
- 수강이력 없이 신청만 있으면 경고를 확인한 뒤 삭제할 수 있습니다. 그 강좌의 희망 선택이 제거되고, 다른 희망이 없는 신청은 신청 전체가 삭제됩니다.
- 삭제 확인 시 아직 저장하지 않은 다른 편집 내용은 취소됩니다. 먼저 저장한 뒤 삭제하세요.

## 2. 수강신청 등록

### Excel로 등록하기

1. **수강신청 → 신청 양식**에서 학기를 선택하고 **양식 다운로드**를 누릅니다.
2. 내려받은 파일의 **수강신청** 시트에 이름과 신청 정보를 입력합니다.
3. **Excel 업로드**에서 파일과 신청 반영 방식을 선택하고 **파일 검토**를 누릅니다.
4. 경고·중복·충돌을 확인하고 필요한 선택이나 확인 사유를 입력합니다.
5. **업무 자료에 반영**을 누르고 목록에 저장됐는지 확인합니다. 검토만으로는 저장되지 않습니다.

신청 양식의 **학기** 시트에는 선택 학기의 이름과 순서, **개설강좌** 시트에는 그 학기의 강좌명과 정원이 들어갑니다. 강좌가 없으면 개설강좌 시트는 비어 있습니다. 이전 학기 강좌가 자동으로 들어가지는 않으므로 먼저 학기·강좌 관리에서 가져오세요.

**개설강좌** 시트에 강좌를 입력했다면 정원을 반드시 적으세요. 빈 정원은 기존 자료에 값이 있어도 오류로 처리되어 업로드할 수 없습니다. 수강신청 시트에 적은 강좌의 정원이 자료에도, 개설강좌 시트에도 없다면 개설강좌 시트에 강좌와 정원을 추가하세요. 정원 0명은 입력할 수 있습니다.

수강신청 시트는 **학기·회원당 한 줄**을 사용하고, 기본 양식에는 **1순위 강좌~4순위 강좌** 열이 있습니다. 2~4순위는 비워도 됩니다. 필요하면 오른쪽에 **5순위 강좌** 열을 추가하세요. 열 이름은 그대로 사용하며 희망 강좌는 한 개 이상, 최대 5개까지 입력합니다. 아래 이름은 기본 양식의 작성 예시입니다.

| 학기명 | 회원명 | 학생 소속 | 신청순서 | 1순위 강좌 | 2순위 강좌 | 3순위 강좌 | 4순위 강좌 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 2026년 가을학기 | 김믿음 | 청년부 | 1 | 창세기 | 마태복음 | 마가복음 | |
| 2026년 가을학기 | 이은혜 | | 2 | 마가복음 | | | |

빈 순위는 건너뛰며 뒤 열의 순위를 당겨 바꾸지 않습니다. 예를 들어 2·3순위를 비우고 `4순위 강좌` 열에 마태복음을 적으면 4순위로 등록됩니다. 같은 학기·회원의 행이나 같은 행의 강좌가 중복되면 오류로 처리합니다. 기존 희망 강좌별 여러 행 양식은 업로드할 수 없으므로 새 양식을 내려받으세요. 현황 내보내기도 같은 한 행 형식이며 실제 등록된 순위에 따라 5순위 열을 포함합니다.

**학생 소속**은 선택 입력이며 최대 200자입니다. 부서·교구·학교 등 필요한 내용을 자유롭게 적고, 비워도 등록할 수 있습니다. 같은 회원도 각 신청과 수강이력에 다른 소속을 저장할 수 있습니다. 소속 열이 없는 기존 버전 `2` Excel은 소속을 빈 값으로 읽으므로 그대로 업로드할 수 있습니다. 새 양식은 버전 `3`입니다.

회원명·학기명·강좌명은 같은 대상을 항상 같은 이름으로 입력하세요. 특히 같은 이름의 회원은 같은 회원으로 처리되므로 동명이인은 구분되는 표기를 사용해야 합니다.

기존 신청이 있으면 **기존 희망 유지** 또는 **파일 내용으로 교체**를 선택하고 검토 결과를 확인하세요. 소속만 달라도 신청 충돌로 표시합니다. 파일 신청으로 교체하면 소속도 파일 값으로 바뀌며, 소속 열이 없는 기존 양식의 소속은 공란이 됩니다. 학기 순서나 정원이 기존 값과 다르면 검토 단계에서 기본적으로 기존 값을 유지하며, 파일 값을 적용할지 별도로 선택합니다.

예를 들어 현재 `창세기` 정원이 10명이고 파일에는 12명이라면, **기존값 유지**는 10명을 그대로 사용하고 **파일값 적용**은 12명으로 바꿉니다. 먼저 실제 운영 정원을 확인하고 선택하세요. 파일의 정원이 빈칸이면 선택으로 해결할 수 없는 오류이므로 Excel에 정원을 적고 다시 검토해야 합니다.

`.xlsx` 파일만 업로드할 수 있습니다. 시트 이름·첫 행의 열 이름·메타 시트는 유지하고, 수식이나 외부 링크 대신 값만 입력하세요. 업로드 파일은 최대 20MiB이며, 더 큰 자료는 나누어 처리하세요.

### 화면에서 직접 등록하기

**신청 등록**에서 학기명, 회원명, 선택 사항인 학생 소속, 신청순서와 희망 강좌를 입력합니다. **희망 추가**로 선택지를 최대 5개까지 늘리고 희망순위는 1~5로 입력합니다. **신청 행 추가**로 회원을 늘려 최대 100건을 **전체 저장**할 수 있습니다. 오류나 중복이 있으면 묶음 전체를 저장하지 않으므로 오류를 수정한 뒤 다시 저장하세요.

신청 수정·삭제는 이미 저장된 수강이력을 바꾸지 않습니다. 소속을 바꿔도 이미 생성한 초안의 소속을 덮어쓰지 않습니다. 다만 확정 전 배정초안의 원본이 달라지므로 변경 안내를 확인하고 다시 검토해야 할 수 있습니다. 소속은 같은 회원을 식별하거나 자동 배정의 우선순위를 정하는 기준으로 사용하지 않습니다.

학기 전체의 신청을 지우려면 수강신청 목록에서 **학기**를 선택한 뒤 **선택 학기 신청 전체 삭제**를 누르세요. 전체 신청 건수와 학기명을 확인하고 학기명을 정확히 입력해야 삭제됩니다. 회원명·강좌명 검색과 페이지 위치에 관계없이 해당 학기의 신청과 희망 강좌 선택이 모두 삭제됩니다. 확인 이후 자료가 변경되면 다시 확인해야 합니다. 학기·개설강좌·회원·수강이력과 저장된 배정초안은 유지되며 기존 초안은 신청 변경 내용을 다시 검토해야 합니다. 필요한 신청을 보관하려면 먼저 회원명·강좌 필터를 해제하고 해당 학기의 **현황 다운로드**를 받으세요.

수강신청 **현황 다운로드**는 검색·정렬을 적용한 전체 신청과 각 신청의 학생 소속을 받습니다. **학기** 시트에는 조회된 신청에 해당하는 학기명·순서를, **개설강좌** 시트에는 해당 학기의 전체 강좌명·정원을 중복 없이 기록합니다. 같은 강좌도 학기별 정원은 구분하며, 회원·강좌 검색으로 학생 수가 줄어도 원래 정원을 유지합니다. 미정인 순서·정원은 빈칸이므로 재업로드 시 검토 안내에 따라 확인하고 값을 입력하세요. 검색 결과가 없으면 각 시트에는 열 제목만 표시합니다.

## 3. 배정초안 검토와 확정

**자동 배정**은 희망 강좌와 정원을 바탕으로 결과를 제안합니다. **수동 초안**은 관리자가 회원과 강좌를 직접 지정할 때 사용합니다. 수동 선택 시 **배정 정책** 칸은 비활성화되며 정책을 적용하지 않습니다. 자동으로 전환하면 다시 선택할 수 있습니다. 수동 초안은 등록된 신청 회원을 미배정으로 표시하며, 신청자가 없어도 빈 초안으로 시작할 수 있습니다.

수동 초안 상세의 **회원 직접 배정**에서 기존 회원명을 선택하거나 새 이름을 입력하고, 필요하면 학생 소속을 적은 뒤 개설 강좌를 골라 **회원 배정 추가**를 누릅니다. 새 이름은 회원으로 함께 등록되며 수강신청은 생성하지 않습니다. 같은 이름은 같은 회원으로 처리하므로 동명이인은 식별 가능한 이름을 사용하세요. 이미 초안에 있는 회원은 기존 행에서 수정하고, 같은 학기의 수강이력이 있는 회원은 이력 화면에서 확인하세요. 자동 초안에 배정할 회원은 수강신청으로 먼저 등록합니다.

회원명 목록에서는 같은 학기에 수강이력이 있는 회원을 제외합니다. 해당 이름을 직접 입력하면 입력란 아래에 안내를 표시하고, 추가를 시도해도 저장하지 않습니다. 과거 학기에만 이력이 있는 회원은 계속 선택할 수 있습니다.

신청 없이 수동 초안을 확정해도 수강이력은 저장됩니다. 다만 홈의 완료 표시는 현재 학기의 신청·배정 업무 순서를 기준으로 하므로 신청이 없는 학기는 완료로 표시되지 않을 수 있습니다.

자동 배정의 **신규 우선**은 과거 학기 수강이력이 없는 회원의 희망을 먼저 살핍니다. **희망순위 우선**은 회원의 1순위·2순위 같은 희망순위를 먼저 비교합니다. 두 정책 모두 남은 자리에 가능한 인원을 대체 배정할 수 있습니다. 어떤 정책이 교회의 운영 기준에 맞는지 정한 뒤 결과를 직접 검토하세요.

1. **배정초안 → 초안 생성**에서 학기와 생성 방식을 선택합니다. 자동 배정이면 정책을 선택하고 준비 상태를 확인하세요. 수동 초안이면 생성 후 회원을 직접 추가하거나 기존 신청자의 최종 결정을 지정합니다.
2. 회원별로 초안 생성 당시 신청순서와 희망 강좌·순위, 자동 배정 결과와 사유를 확인합니다. 직접 추가한 회원은 **신청 없음**으로 표시됩니다. 이미 같은 학기에 수강이력이 있는 회원은 기존 확정 인원으로 취급합니다.
3. 필요한 회원의 **최종 결정**에서 강좌 또는 제외를 선택하고 행의 **저장**을 누릅니다. **학생 소속**은 신청 당시 값이 복사되어 있으며 행에서 수정하거나 비울 수 있습니다. 소속만 수정해도 행의 **저장**을 누르세요. 원래 신청이나 다른 학기의 소속에는 영향을 주지 않습니다. 자동 결과와 다른 행은 배경색으로 구분됩니다.
4. 행의 **저장**을 누르면 수정 내용이 바로 저장됩니다. **닫기**로 창을 닫고 나중에 다시 열어 검토할 수 있습니다. **확정**은 저장된 최종 결정의 경고·오류와 강좌별 인원을 확인하는 검토 창을 엽니다. 저장 전 선택은 확정 검토에 반영되지 않으므로 먼저 행을 저장하세요. **관리자 메모**는 필요한 경우에만 기록합니다.
5. 검토 창의 **이번 추가 학생**에서 소속과 배정 강좌를 확인합니다. **검토 내용으로 확정**을 누르면 초안에 저장한 소속과 선택된 결과가 수강이력에 저장되고, 확정한 초안은 목록에서 제거됩니다.

행의 **자동 복원**은 최종 결정·강좌를 자동 배정 결과로 되돌리고 관리자 변경 사유를 지웁니다. 저장한 학생 소속은 유지합니다. 소속을 바꾸려면 해당 행에서 수정한 뒤 **저장**을 누르세요.

자동 배정의 동률 처리는 균등 추첨을 보장하는 기능이 아닙니다. 자동 결과를 검토한 뒤 관리자가 최종 결정을 확정하세요.

초안 상세는 한 번에 50명씩 표시합니다. **이전·다음**으로 이동하거나 검색·필터로 대상을 좁힐 수 있습니다. 검색과 정렬은 전체 결과에 적용되며, 강좌 선택창을 열면 해당 학기의 모든 개설 강좌가 표시됩니다. 자동 사유를 펼치면 상세한 배정 근거를 확인할 수 있습니다.

**강좌별 정원 현황**은 창을 스크롤해도 상단에 표시됩니다. 기존 수강이력과 초안의 최종 배정 인원을 합산하여 정원·잔여 인원을 표시하며 검색·필터와 관계없이 전체 초안을 기준으로 계산합니다. 강좌 목록에도 인원과 **정원 마감**, **정원 초과**를 표시합니다. 정원은 초안 생성 당시 값이며, 미정인 경우 별도로 표시합니다.

강좌 선택을 바꾸면 현재 화면의 저장 전 선택을 현황에 미리 반영합니다. 실제 반영은 해당 행의 **저장**을 눌러야 합니다. 저장·자동 복원 또는 검색·페이지 이동으로 행을 다시 표시하면 저장된 초안 기준으로 현황을 갱신합니다. 정원이 찬 강좌도 관리자 판단으로 선택할 수 있으며, 초과 배정은 확정 검토에서 경고를 확인합니다.

**원본 자료가 변경되었습니다**가 표시되면 신청·이력·강좌 설정 변경을 확인하고 새 초안을 만드세요. 사용하지 않을 진행 중 초안은 목록에서 삭제할 수 있습니다. 확정 후 이력 정정은 수강이력 화면에서 합니다.

초안 생성 뒤 추가한 강좌는 **현황 미확인 · 새 초안 필요**로 표시합니다. 해당 강좌의 초안 배정 인원은 표시하지만 기존 이력·정원·잔여는 추정하지 않습니다. 새 초안을 생성해 현황을 확인하세요.

진행 중 초안을 삭제해도 수강이력은 남습니다. 홈의 업무 안내는 진행 중 초안과 학기의 확정 기록을 참고하므로 새 초안을 만들면 안내 단계가 달라질 수 있습니다.

## 4. 수강이력 확인과 학기 업무 완료

### 기존 이력 입력과 수정

목록의 **정렬**에서 회원명·강좌명의 가나다순·역순 또는 학기 최신 순·이전 순을 선택합니다. 기본은 **등록순**입니다. 학기는 **학기·강좌 관리**의 학기 순서를 기준으로 하며 순서 미정은 마지막에 표시합니다. 검색 결과 전체를 정렬한 뒤 페이지를 나누며, 정렬을 바꾸면 첫 페이지로 이동합니다. 검색·페이지 이동·목록 새로고침은 선택한 정렬을 유지합니다.

**이력 등록**에서 직접 입력하거나 **이력 양식**의 **수강이력** 시트에 `학기명 / 회원명 / 학생 소속 / 강좌명 / 관리자 메모`를 채워 **Excel 업로드**로 등록합니다. 학생 소속은 선택 입력이며 최대 200자이고, 관리자 메모는 선택 입력이며 최대 2,000자입니다. 수강신청·배정초안 없이도 가능합니다. 최신 양식은 버전 `3`이며 소속 열이 없는 버전 `2` 파일도 업로드할 수 있습니다. 이력의 소속을 수정하거나 비워도 신청·초안·다른 학기의 이력은 바뀌지 않습니다.

별도 **개설강좌** 시트에는 `학기명 / 강좌명 / 정원`을 강좌당 한 행씩 입력합니다. 정원은 0 이상의 정수이며 미정이면 `미정`을 적습니다. 강좌 행을 적고 정원을 비우면 오류입니다. 기존 정원과 다르면 검토 화면에서 **기존 값 유지** 또는 **파일 값 적용**을 선택합니다.

Excel에 적은 새 학기와 강좌는 이력과 함께 등록됩니다. 학기는 다음 순서를 받고, 개설강좌 시트에 정원을 지정하면 해당 값을 사용합니다. 강좌 행을 생략하면 새 강좌 정원은 첫 등록 작업의 학생 수로 설정된다는 안내가 표시됩니다. 안내의 **닫기**를 눌러 숨길 수 있으며 확인 메모는 필요하지 않습니다. 이후 이력을 추가·수정·삭제해도 기존 정원은 바뀌지 않습니다. 파일 전체의 누적 인원과 재수강을 검토하며 정원 충돌은 두 선택에서 발생할 수 있는 경고를 모두 표시합니다.

직접 입력할 때 **이력 행 추가**로 최대 100건을 묶어서 **검토 후 저장**합니다. 같은 회원의 같은 학기 수강이력은 1건만 허용되며 중복은 저장할 수 없습니다.

신청·이력 입력과 Excel 검토 화면의 **입력 경고 무시**를 체크하면 등록의 안내·경고 확인을 생략합니다. 체크를 해제하면 정원 미정·정원 초과·재수강 경고를 확인합니다. 관리자 메모는 선택 입력이며 비워 두어도 저장할 수 있습니다. 오류는 항상 표시되며 저장을 막고, 기존 값·파일 값의 충돌은 계속 선택해야 합니다. 이 설정은 배정 확정 검토에는 적용되지 않습니다. 현재 화면에서 공유되며 화면을 새로 열면 기본으로 체크가 해제됩니다.

직접 등록·수정·Excel 반영·배정 확정 때 입력한 **관리자 메모**는 수강이력 목록의 **메모 보기**를 눌러 전체 내용과 기록 시각을 확인합니다. 빈 메모는 `—`로 표시됩니다. Excel의 학생별 메모는 입력 경고를 무시해도 저장하며, 경고 확인 창의 공통 메모보다 우선합니다. 공통 메모는 실제 경고가 있는 행에만 저장합니다. 이미 같은 이력이 있으면 기존 이력과 메모를 유지합니다.

Excel 검토 후 파일을 다시 선택하거나 신청 반영 방식을 바꾸면 이전 검토 결과가 사라지고 **파일 검토** 버튼이 다시 표시됩니다. 새 검토가 끝난 뒤 업무 자료에 반영하세요. 검토 항목은 한 줄로 표시되며 긴 문구는 마우스를 올려 전체 내용을 확인할 수 있습니다.

수강신청·수강이력 Excel 검토의 **반영 후보** 목록은 기본으로 접혀 있습니다. **상세보기**로 펼치고 **상세접기**로 다시 접습니다. 각 후보의 학기·회원·학생 소속·강좌 정보는 한 줄로 표시하며 긴 내용은 말줄임 처리합니다. 마우스를 올리면 전체 내용을 확인할 수 있습니다. 목록을 접어도 검토 건수·검토 항목·충돌 처리·반영 버튼은 계속 표시되며 자료를 반영할 수 있습니다. 파일을 다시 선택하거나 신청 반영 방식을 바꾸고 새로 검토하면 목록은 다시 접힙니다.

행의 **수정**에서 학기명과 학생 소속을 바꾸고 강좌를 드롭다운으로 선택할 수 있습니다. 소속을 비우면 해당 이력의 소속만 삭제됩니다. 새 강좌가 필요하면 **새 강좌 입력**을 선택합니다. **관리자 메모 (선택)**에는 기존 메모가 표시되며, 내용을 바꾸거나 비워서 삭제할 수 있습니다. 경고가 없거나 **입력 경고 무시**를 체크해도 작성한 메모는 저장됩니다. 경고 확인 창이 열리면 작성한 메모가 채워지며 확인 창에서 보완한 내용을 저장합니다. 신청이나 초안을 삭제해도 이력은 유지되며, 이력을 지우려면 이력 화면에서 별도로 삭제해야 합니다.

같은 학기·회원·강좌의 이력이 있어도 파일의 소속이 다르면 반영을 막습니다. 목록의 기존 소속과 파일을 비교하고, 정정이 필요하면 이력 화면에서 수정하세요. 소속 열이 없는 기존 양식은 공란으로 비교하므로 소속이 저장된 이력과 충돌할 수 있습니다. **입력 경고 무시**로 이 충돌을 건너뛸 수 없습니다.

학기 전체의 이력을 지우려면 수강이력 목록에서 **학기**를 선택한 뒤 **선택 학기 이력 전체 삭제**를 누르세요. 삭제 건수와 학기명을 확인하고 학기명을 정확히 입력해야 삭제됩니다. 회원명·강좌명 검색과 페이지 위치에 관계없이 해당 학기의 이력이 모두 삭제되며, 수강신청과 배정초안은 유지됩니다. 필요한 이력을 보관하려면 먼저 회원명·강좌 필터를 해제하고 해당 학기의 **현황 다운로드**를 받으세요.

### 두 가지 현황 다운로드

| 버튼 | 내려받는 내용 | 홈의 업무 완료 표시 |
| --- | --- | --- |
| 오른쪽 위 **현황 다운로드** | 현재 회원명·학기·강좌 검색 조건과 선택한 정렬을 적용한 전체 이력. 현재 페이지에 한정하지 않음 | 변경하지 않음 |
| 안내 상자의 **현재 학기 현황 다운로드** | 검색 조건과 관계없이 현재 학기 전체 이력 | 해당 학기의 확정 기록을 기준으로 완료 기록 |

두 파일 모두 **수강이력** 시트에 학생 소속·관리자 메모를, **개설강좌** 시트에 내려받은 이력의 강좌별 정원을 포함합니다. 같은 강좌는 한 행만 포함하며 일부 학생만 검색해 내려받아도 정원은 원래 설정값을 유지합니다. 정원 미정은 `미정`으로 표시됩니다.

현재 학기의 배정을 확정한 뒤 수강이력 화면의 명단을 확인하고 **현재 학기 현황 다운로드**를 누르세요. 홈으로 돌아가면 앞 단계의 조건도 충족된 경우 **현재 학기 업무가 완료되었습니다**가 표시됩니다. 브라우저에서 실제 파일이 내려받아졌는지도 확인하세요.

업무 완료 기록은 내려받은 시점의 자료 버전을 기준으로 합니다. 현재 학기 외의 자료라도 등록·수정·삭제해 자료 버전이 바뀌면 다시 다운로드하도록 안내될 수 있습니다. 파일 생성 도중 자료가 바뀌어 충돌 안내가 나오면 목록을 새로고침하고 다시 시도하세요.

신청·초안 없이 과거 이력만 등록한 경우에도 이력 관리와 일반 현황 다운로드는 가능합니다. 홈의 완료 표시는 **현재 학기의 신청·배정 업무 흐름**을 기준으로 하므로 이력 보유 여부만으로 완료되지는 않습니다.

### 다운로드 파일 찾기

파일은 브라우저의 다운로드 목록 또는 다운로드 폴더에서 찾습니다. 양식과 현황 파일명에는 PC의 다운로드 시각이 `YYMMDDHHMMSS` 형식으로 붙습니다.

- `수강신청_양식_260925143015.xlsx`
- `수강이력_양식_260925143015.xlsx`
- `수강신청_현황_260925143015.xlsx`
- `수강이력_현황_260925143015.xlsx`

## Excel로 자료 보관과 재등록

전체 자료를 보관하려면 **수강신청**과 **수강이력**에서 검색·필터를 해제하고 각각 **현황 다운로드**를 받습니다. 현재 페이지와 관계없이 검색 조건에 해당하는 전체 행이 저장됩니다. 파일을 USB 등 별도 저장 장치에도 복사하세요.

수강이력 파일의 **수강이력** 시트에는 학기명·회원명·학생 소속·강좌명·관리자 메모가 저장됩니다. **개설강좌** 시트에는 해당 이력의 학기명·강좌명·정원이 한 행씩 저장되며 정원 미정은 `미정`으로 구분됩니다.

수강신청 파일에는 조회된 신청의 **학기** 이름·순서와 해당 학기의 전체 **개설강좌** 이름·정원이 포함됩니다. 신청이 없는 학기의 설정은 포함하지 않습니다.

재등록은 각 화면의 **Excel 업로드 → 파일 검토 → 업무 자료에 반영** 순서입니다. 같은 학기·회원·강좌·소속의 이력은 기존 이력·메모를 유지합니다. 소속이 다르면 이력 화면에서 확인 후 수정하고, 정원 충돌은 기존 값 유지 또는 파일 값 적용을 선택합니다. 신청은 수강신청 Excel을 업로드합니다. 배정초안·시스템 기록은 보관되지 않으며 학기 순서는 신청 현황에 포함된 학기만 보관하므로 재등록 후 확인하고 필요한 초안을 새로 만드세요.

수동 `.sqlite` 백업·복원 화면은 제공하지 않으며 기존 자료 파일은 그대로 유지됩니다. 업데이트의 자료 형식 변경 전 안전 사본은 자료 폴더의 `update-backups`에 자동 보관됩니다. 자료 위치와 프로그램 업데이트 절차는 [문제 해결](troubleshooting.md#excel-자료-보관과-업데이트)에 있습니다.

실행 오류나 배포 파일 문제는 [문제 해결](troubleshooting.md)을 참고하세요. 공개 문의에는 실제 회원 명단이나 백업 파일을 첨부하지 마세요.
